Squadrats for Mapy.com

1. Import your visited tiles

On squadrats.com open the map and use Download KML. Then choose the file here. You can import the squadrats and squadratinhos as one file or as two separate files.

Importing replaces previously imported tiles of the same kind.

3. Alignment (only if the grid looks off)

Open a Mapy.com map and compare it with the same place on squadrats.com. If the grid cells are twice or half the expected size, change the zoom offset to -1 or 1 (fractions work too). If the whole grid is shifted by a constant number of pixels, nudge it with the offsets.
